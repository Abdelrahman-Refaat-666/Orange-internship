# Orange Innovation Egypt - C++ Internship

My work from the C++ track internship at **Orange Innovation Egypt** (26 July 2025 - 26 August 2025).

## Projects

| Project | Description |
|---|---|
| [Project 1 - Linear Equations Solver](Project%201) | reads up to 100 linear equations, does add / subtract / substitute on them and solves them with Cramer's rule |
| [Project 2 - Hospital Topology](Project%202) | a hospital built as a tree (departments, doctors, nurses, rooms, patients) using OOP |

## Sheets

The `Sheet` folders have my solutions for the weekly sheets (basics, structs, loops, arrays, pointers, classes, operator overloading, inheritance).

## Build

I used g++ (MinGW) with VS Code. To build any file:

```
g++ main.cpp -o main
```
